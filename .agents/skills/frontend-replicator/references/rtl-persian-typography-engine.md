# RTL, Persian Typography & Motion Vector Engine Guide
# راهنمای جامع راست‌چین‌سازی (RTL)، کالیبراسیون تایپوگرافی فارسی و معکوس‌سازی بردارها

تبدیل یک رابط کاربری انگلیسی (LTR) به یک شاهکار فارسی (RTL)، صرفاً افزودن مشخصه `dir="rtl"` نیست؛ بلکه نیازمند **مهندسی معکوس فیزیک تایپوگرافی، معکوس‌سازی بردارهای حرکتی GSAP و جایگزینی کامل ویژگی‌های فیزیکی CSS با ویژگی‌های منطقی (Logical Properties)** است.

---

## ۱. سه فاجعه فنی در ترجمه ناشیانه LTR به RTL و راه‌حل آن‌ها

| فاجعه فنی در روش ناشیانه | علت فیزیکی در زبان فارسی | راه‌حل مهندسی و قطعی |
| :--- | :--- | :--- |
| **۱. تکه‌تکه شدن حروف در انیمیشن‌ها** | انیمیشن‌های متنی کاراکتر‌محور (`chars` split) حروف پیوسته فارسی را جدا می‌کنند (مثلاً «ه و ش م ن د»). | **ممنوعیت مطلق Split Chars؛** در فارسی انیمیشن متن فقط بر اساس کلمات (`words`) یا خطوط (`lines`) با `text.split(' ')` اجرا می‌شود. |
| **۲. تصادم خطوط و سرکش‌ها** | استفاده از `tracking-tighter` منفی و `leading-none` فشرده انگلیسی باعث برخورد سرکش‌های «ک/گ» و نقطه‌ها با خط بالا می‌شود. | **حذف کامل Tracking منفی؛** افزایش Line-Height در تیترها به `leading-[1.35]` یا `leading-snug` و متن بدنه به `leading-relaxed`. |
| **۳. جهت معکوس حرکت چشم و المان‌ها** | انیمیشن‌های ورود از چپ به راست و فلش‌های رو به راست با جهت خوانش چشم فارسی‌زبان در تضاد هستند. | **معکوس‌سازی بردارهای X در GSAP** (`x: -100` $\rightarrow$ `x: 100`) و کلاس `rtl:-scale-x-100` برای آیکون‌های جهت‌دار. |

## ۲. جدول نگاشت ۱ به ۱ فونت‌های Variable فارسی به جای فونت‌های انگلیسی

سایت‌های مدرن انگلیسی برنده جایزه از فونت‌های متغیر با وزن‌های میانی (مانند `font-weight: 540` یا `650`) استفاده می‌کنند. برای حفظ وزن بصری دقیق، معادل فارسی متغیر آن انتخاب می‌شود:

| سبک و شخصیت فونت انگلیسی | نمونه‌های معروف انگلیسی | معادل پیشنهادی فارسی (رایگان/متن‌باز) | معادل پیشنهادی فارسی (تجاری/سازمانی) | کاربرد و حس بصری |
| :--- | :--- | :--- | :--- | :--- |
| **مدرن، خنثی و تکنولوژیک** | Inter, Geist, SF Pro, Roboto | **Vazirmatn (وزیرمتن متغیر)** | **IRANSansX (ایران‌سنس ایکس)** یا **Dana (دانا متغیر)** | داشبوردها، متن‌های بدنه، سایت‌های SaaS و اپلیکیشن‌ها |
| **هندسی، جسورانه و نمایشی هیرو** | Plus Jakarta Sans, Clash Display, Satoshi, Syne | **Vazirmatn UI (Bold/Black)** | **Peyda (پیدا متغیر)** یا **Yekan Bakh (یکان‌باخ متغیر)** | تیترهای غول‌آسا، صفحات فرود لوکس و محصولات مدرن |
| **کلاسیک، پرستیژ و ادیتوریال** | Lora, Playfair Display, Serif | **Vazirmatn (وزن‌های سبک/ایتالیک)** | **Estedad (استعداد)** یا **IranNastaliq / انجمن** | پلتفرم‌های مربی‌گری، لوکس و مقالات فرهنگی |

## ۳. جدول نگاشت ویژگی‌های فیزیکی به ویژگی‌های منطقی (Tailwind Logical Properties)

هرگز از کلاس‌های فیزیکی چپ/راست در کامپوننت‌های مدرن استفاده نکنید:

| ویژگی فیزیکی (منسوخ در RTL) | ویژگی منطقی معادل (Tailwind Logical) | رفتار در LTR (انگلیسی) | رفتار در RTL (فارسی) |
| :--- | :--- | :--- | :--- |
| `ml-*` (Margin Left) | `ms-*` (Margin Start) | حاشیه از سمت چپ | حاشیه از سمت راست |
| `mr-*` (Margin Right) | `me-*` (Margin End) | حاشیه از سمت راست | حاشیه از سمت چپ |
| `pl-*` (Padding Left) | `ps-*` (Padding Start) | فاصله داخلی چپ | فاصله داخلی راست |
| `pr-*` (Padding Right) | `pe-*` (Padding End) | فاصله داخلی راست | فاصله داخلی چپ |
| `left-*` (Position Left) | `start-*` | چسبیدن به چپ | چسبیدن به راست |
| `right-*` (Position Right) | `end-*` | چسبیدن به راست | چسبیدن به چپ |
| `text-left` | `text-start` | تراز چپ | تراز راست |
| `text-right` | `text-end` | تراز راست | تراز چپ |
| `border-l-*` | `border-s-*` | خط حاشیه چپ | خط حاشیه راست |
| `border-r-*` | `border-e-*` | خط حاشیه راست | خط حاشیه چپ |
| `rounded-l-*` | `rounded-s-*` | گوشه‌های گرد چپ | گوشه‌های گرد راست |
| `rounded-r-*` | `rounded-e-*` | گوشه‌های گرد راست | گوشه‌های گرد چپ |

## ۴. اعداد و ارقام فارسی در سطح CSS (`font-feature-settings`)

برای اینکه تمامی اعداد انگلیسی بدون دستکاری دیتای اصلی، با کاراکترهای زیبای فارسی نمایش یابند:

```tsx
// فعال‌سازی اعداد فارسی روی کانتینر ریشه یا متون
<div className="[font-feature-settings:'ss01'] font-sans" dir="rtl">
  {/* در اینجا تمام ارقام مثل 1234 به صورت ۱۲۳۴ رندر می‌شوند */}
</div>
```

برای فرمت‌دهی جداکننده سه‌رقمی قیمت‌ها و تاریخ‌ها از پکیج سبک `@persian-tools/persian-tools` استفاده کنید:
```typescript
import { addCommas, digitsEnToFa } from '@persian-tools/persian-tools';

const formattedPrice = digitsEnToFa(addCommas(1250000)) + ' تومان'; // ۱,۲۵۰,۰۰۰ تومان
```

## ۵. معکوس‌سازی بردارهای حرکتی در GSAP و Framer Motion

### ۱. محور افقی X در GSAP:
هر جا المانی در نسخه انگلیسی با مقدار منفی X وارد می‌شود، در فارسی باید مثبت شود:
```tsx
// نسخه انگلیسی (ورود از چپ):
gsap.from('.hero-content', { x: -60, opacity: 0 });

// نسخه فارسی (ورود متقارن از راست):
gsap.from('.hero-content', { x: 60, opacity: 0 });
```

### ۲. آیکون‌های جهت‌دار و هاور دکمه‌ها:
```tsx
// دکمه با هاور قرینه در حالت RTL
<button className="group inline-flex items-center gap-2">
  <span>شروع کنید</span>
  <ArrowLeft className="h-4 w-4 transition-transform group-hover:-translate-x-1" />
</button>
```

### ۳. گرادینت‌های افقی:
- `bg-gradient-to-r` در انگلیسی $\rightarrow$ به `bg-gradient-to-l` در فارسی تبدیل شود تا شروع رنگ با شروع چشم کاربر در سمت راست همگام باشد.

## ۶. تکنیک تناسب‌سنجی سایز فونت (UX Transcreation & Typographic Scaling)

کلمات فارسی به طور میانگین بین **۱۵٪ تا ۲۵٪ پهن‌تر و بلندتر** از حروف فشرده انگلیسی هستند. برای جلوگیری از به هم ریختن چیدمان خطوط:
- **کاهش ۵ تا ۱۰ درصدی سایز تایتل‌های بسیار درشت:**
  اگر در انگلیسی تایتل هیرو `text-7xl` (`72px`) بود، در فارسی از `text-6xl` (`60px`) یا `text-5xl lg:text-6xl` استفاده کنید.
- **انتخاب واژگان کوبنده و مینی‌مال:**
  به جای ترجمه طویل ماشینی، مفهوم را در قالب کلمات کوتاه، موثر و هم‌تراز با ادبیات استارتاپ‌های پیشرو بنویسید تا همان تعداد سطر حفظ شود.

## ۷. استانداردهای Impeccable برای ریتم فضایی و ارتفاع خطوط (Spatial Rhythm & Leading Matrix)

| المان متنی | کلاس پیشنهادی Tailwind | بازه نسبت ارتفاع خط (Line-Height Ratio) | ملاحظات حیاتی و فاصله مجاورتی |
| :--- | :--- | :--- | :--- |
| **تایتل هیرو (H1)** | `leading-[1.3] sm:leading-[1.26] lg:leading-[1.24]` | ۱.۲۴ تا ۱.۳۲ | حذف کامل `tracking-tight`، اعمال `tracking-normal`، توازن با `text-wrap: balance` |
| **تیتر سکشن‌ها (H2)** | `leading-[1.38] sm:leading-[1.35] lg:leading-[1.32]` | ۱.۳۲ تا ۱.۴۰ | عدم استفاده از `text-5xl` بدون leading صریح؛ فاصله تا ساب‌تایتل: `mt-5 sm:mt-6` |
| **تیتر کارت‌ها (H3)** | `leading-[1.36] sm:leading-[1.32]` | ۱.۳۲ تا ۱.۳۸ | جلوگیری از چسبیدن به بج بالایی یا توضیحات پایینی |
| **بج و نشان بالا (Eyebrow)** | `mb-5 sm:mb-6 px-4 py-1.5` | — | فاصله سخاوتمندانه تا تیتر اصلی؛ هرگز `mb-2` یا `mb-3` داده نشود تا یکپارچگی تنفسی حفظ شود |
| **متن بدنه و توضیحات (Body)** | `leading-[1.75] sm:leading-[1.85]` | ۱.۷۵ تا ۱.۸۵ | کنترل طول سطر بین ۵۰ تا ۷۰ کاراکتر (`max-w-xl`) جهت خوانایی بی‌نقص |
