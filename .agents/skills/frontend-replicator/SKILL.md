## ۲. اولویت‌بندی ۱۰ گانه قوانین طراحی (Priority 1→10 Rule Hierarchy)

هنگام طراحی، پیاده‌سازی یا بازرسی هر صفحه یا کامپوننت، رعایت اولویت‌های زیر الزامی است:

| اولویت | دسته‌بندی | سطح اهمیت | دامنه جستجو (`--domain`) | چک‌های الزامی (Must-Have) | الگوهای ممنوعه (Anti-Patterns) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **۱** | **Accessibility (دسترسی‌پذیری)** | حیاتی (CRITICAL) | `ux` | کنتراست ۴.۵:۱ متن، حلقه فوکوس کیبورد، Alt تصاویر، `aria-label`، عدم پوشش فوکوس توسط المان‌های شناور | حذف Outline بدون جایگزین، دکمه‌های آیکونی بدون برچسب، انتقال اطلاعات صرفاً با رنگ |
| **۲** | **Touch & Interaction (لمس و تعامل)** | حیاتی (CRITICAL) | `ux` | اندازه تاچ تارگت حداقل ۴۴×۴۴ پیکسل (۴۸ در اندروید)، فاصله ۸ پیکسلی، بازخورد سریع کلیک (زیر ۱۰۰ میلی‌ثانیه)، دکمه‌های لودینگ | وابستگی صرف به هاور، تغییر ناگهانی استیت بدون فیدبک، جابجایی کادر المان‌ها هنگام فشردن |
| **۳** | **Performance (کارایی و سرعت)** | بالا (HIGH) | `ux`, `react` | فرمت‌های WebP/AVIF، بارگذاری تنبل (Lazy Load)، حفظ نسبت تصویر (CLS < 0.1)، فونت با `font-display: swap` | تغییرات ناگهانی چیدمان (Layout Shift)، کامپوننت‌های سنگین بدون Suspense، واکشی مسدودکننده |
| **۴** | **Style Selection (انتخاب سبک)** | بالا (HIGH) | `style`, `product` | تطابق سبک با نوع محصول (با `--design-system`)، یکدستی کامل آیکون‌ها و المان‌ها، استفاده از وکتور SVG | استفاده از ایموجی به عنوان آیکون، گرادیان‌های کلیشه‌ای بنفش/صورتی هوش مصنوعی، ترکیب شلخته فلت و اسکیومورفیسم |
| **۵** | **Layout & Responsive (چیدمان واکنش‌گرا)** | بالا (HIGH) | `ux` | رویکرد اکیداً موبایل‌فرست، رعایت Safe Areas، ممانعت قطعی از اسکرول افقی (`scrollWidth <= innerWidth`) | اسکرول افقی ناخواسته، عرض ثابت پیکسلی فراتر از ۱۰۰vw، پوشانده شدن دکمه‌های CTA زیر خط تا در لپ‌تاپ |
| **۶** | **Typography & Color (رنگ و تایپوگرافی)** | متوسط (MEDIUM) | `typography`, `color` | فونت پایه ۱۶px، ارتفاع خط مناسب (Line-height Floor)، توکن‌های معنایی رنگ، کنتراست مستقل تم روشن و تاریک | استفاده از کدهای هگز خام پراکنده در کامپوننت‌ها، متن خاکستری روی خاکستری، لترینگ منفی در فونت فارسی |
| **۷** | **Animation (انیمیشن و حرکت)** | متوسط (MEDIUM) | `ux`, `gsap` | زمان‌بندی طبیعی و هماهنگ، انتقال معنا با حرکت، رعایت کامل `prefers-reduced-motion` | انیمیت کردن width یا height، زمان ثابت برای تمام انیمیشن‌ها، شکستن حروف فارسی در SplitText |
| **۸** | **Forms & Feedback (فرم‌ها و بازخورد)** | متوسط (MEDIUM) | `ux` | برچسب‌های مرئی، نمایش خطای اعتبارسنجی چسبیده به اینپوت، متن راهنما، افشای تدریجی اطلاعات (Progressive Disclosure) | استفاده از Placeholder به عنوان برچسب اصلی، نمایش تمام خطاها در بالای فرم، فرم‌های بی‌پایان یک‌مرحله‌ای |
| **۹** | **Navigation (ناوبری و منوها)** | بالا (HIGH) | `ux` | رفتار قابل پیش‌بینی دکمه بازگشت، دراور موبایل استاندارد، آیتم‌های Bottom Nav حداکثر ۵ مورد، لینک‌پذیری عمیق | منوهای شلوغ و گیج‌کننده، اختلال در عملکرد دکمه Back مرورگر، لینک‌های شکسته |

## ۳. موتور جستجو و تولیدکننده دیزاین سیستم (`scripts/search.mjs` و `scripts/search.py`)

این اسکیل مجهز به یک رانر بومی، بدون نیاز به پیش‌نیاز خارجی و کراس‌پلتفرم در **Node.js** و همچنین اسکریپت اصلی پایتون است. 

### نحوه اجرای ابزار جستجو:

```bash
# با استفاده از Node.js (پیشنهادی و سازگار با همه محیط‌ها):
node "<skill-path>/scripts/search.mjs" "<query>" --domain <domain>

# یا در پروژه با مسیر نسبی:
node .agents/skills/frontend-replicator/scripts/search.mjs "<query>" --domain <domain>

# در صورت وجود پایتون:
python "<skill-path>/scripts/search.py" "<query>" --domain <domain>
```

### ۱. قراردادهای جستجو (Query Contracts):
* **تولید کامل دیزاین سیستم برای پروژه/صفحه جدید:** از سوئیچ `--design-system` استفاده کن.
* **بررسی موضوع یا کامپوننت خاص:** از سوئیچ صریح `--domain` استفاده کن (`style`, `color`, `chart`, `landing`, `product`, `ux`, `typography`, `icons`, `gsap`, `react`, `web`, `google-fonts`).
* **استک پیاده‌سازی:** از سوئیچ `--stack` استفاده کن (مانند `--stack nextjs` یا `--stack html-tailwind`).

### ۲. تنظیمات ۳ لغزنده دیزاین (Design Dials):
هنگام اجرای `--design-system`، می‌توانید ۳ اسلایدر مقداری بین ۱ تا ۱۰ را تنظیم کنید:
* `--variance <1-10>`:
  - مقادیر ۱ تا ۳: مینیمال و متقارن (Centered / Minimal)
  - مقادیر ۴ تا ۷: متوازن و مدرن (Balanced / Modern)
  - مقادیر ۸ تا ۱۰: جسورانه و نامتقارن (Bold / Asymmetric / Bento Grids / Brutalism)
* `--motion <1-10>`:
  - مقادیر ۱ تا ۳: انیمیشن‌های ملایم و ریز (Subtle Micro-interactions)
  - مقادیر ۴ تا ۷: موشن استاندارد اسکرول و استگر (Standard Motion)
  - مقادیر ۸ تا ۱۰: انیمیشن‌های چندمرحله‌ای پیچیده (Complex Choreography / Pinning)
* `--density <1-10>`:
  - مقادیر ۱ تا ۳: مقیاس باز و فاصله‌دار (Spacious: 24px-96px) مخصوص صفحات لندینگ لوکس
  - مقادیر ۴ تا ۷: مقیاس استاندارد (Standard: 16px-64px)
  - مقادیر ۸ تا ۱۰: مقیاس فشرده داشبوردی (Dense: 8px-32px) مخصوص ابزارهای کاری و آنالیتیکس

### ۳. ماندگارسازی دیزاین سیستم (Master + Overrides Pattern):
با افزودن سوئیچ `--persist` و تعیین مسیر پروژه با `--output-dir`، فایل منبع حقیقت ساخته می‌شود:
```bash
node .agents/skills/frontend-replicator/scripts/search.mjs "SaaS analytics tool" --design-system -p "My SaaS" --variance 8 --motion 7 --density 8 --persist --output-dir "."
```
این دستور فایل‌های زیر را تولید و مدیریت می‌کند:
* `design-system/<project-slug>/MASTER.md`: منبع حقیقت واحد کل پروژه (رنگ‌ها، تایپوگرافی، پترن‌ها، فاصله‌ها).
* `design-system/<project-slug>/pages/<page-name>.md`: اوررایدهای خاص یک صفحه فرعی (با پاس دادن `--page "dashboard"`).

## ۴. خط لوله بازآفرینی، کالبدشکافی و مهندسی معکوس رابط کاربری (Replication Pipeline)

هنگامی که کاربر آدرس اینترنتی زنده (`[URL]`) یا تصویر/اسکرین‌شات ارائه می‌دهد:

### دو حالت کاری مهارت (Operating Modes):
1. **حالت ۱: شبیه‌سازی دقیق ۱ به ۱ (Exact 1:1 Clone Mode):**
   تولید کامپوننت با دقیقاً همان پالت رنگی، هارمونی و نسبت‌های بصری سایت مرجع.
2. **حالت ۲: برندینگ و نگاشت هویت سازمانی (Brand Remap Mode):**
   نگاشت معنایی نقش‌های رنگی و استایل‌های سایت مرجع به دیزاین‌سیستم مقصد (مانند پروژه بلومیا کلاب در `AGENTS.md` یا دیزاین سیستم استخراج‌شده).

### گام اول: سیاهه کامل ساختار صفحه (Full-Page DOM Inventory)
پیش از نوشتن کد، کل المان‌های تگ `<body>` یا `<main>` و بنرهای میانی را پیمایش کن تا مطمئن شوی هیچ سکشن یا بنر بینابینی جا نمی‌افتد (پروتکل سیاهه کامل).

### گام دوم: ثبت بصری دسکتاپ و موبایل با Playwright
اجرای اسکریپت خودکار استخراج:
```bash
node .agents/skills/frontend-replicator/scripts/extract-component.mjs --url "[TARGET_URL]" --selector "[OPTIONAL_SELECTOR]" --output "extracted-ui"
```
تصاویر استخراج‌شده را بلافاصله بررسی کن تا وزن بصری، توازن فضای منفی و سلسله‌مراتب بصری را تحلیل نمایی.

### گام سوم: استخراج عمیق Computed Styles و رنگ‌ها
کدهای استایل محاسبه‌شده، پالت‌های پس‌زمینه، متن‌ها، بردرها، سایه‌ها و گرادیان‌ها توسط اسکریپت در مرورگر استخراج می‌شوند.

## ۶. موتور بومی‌سازی، راست‌چین‌سازی (RTL) و تایپوگرافی فارسی

هنگام بازآفرینی سایت‌های انگلیسی (LTR) به زبان فارسی (RTL)، اعمال صرفاً `dir="rtl"` خطای فاحش است. ایجنت **موظف است ۶ قانون سخت‌گیرانه زیر را اعمال کند**:

### ۱. معماری Logical Properties در Tailwind CSS
هرگز از کلاس‌های جهت‌دار فیزیکی استفاده نکن:
* `ms-*` و `me-*` به جای `ml-*` و `mr-*` (Margin Start / End)
* `ps-*` و `pe-*` به جای `pl-*` و `pr-*` (Padding Start / End)
* `start-*` و `end-*` به جای `left-*` و `right-*`
* `text-start` و `text-end` به جای `text-left` و `text-right`
* `border-s-*` و `border-e-*` به جای `border-l-*` و `border-r-*`
* `rounded-s-*` و `rounded-e-*` به جای `rounded-l-*` و `rounded-r-*`

### ۲. کالیبراسیون فیزیک تایپوگرافی و ریتم فضایی (Persian Font Physics & Spatial Rhythm)
* **ممنوعیت مطلق Letter-Spacing منفی:** اگر سایت مبدا دارای `tracking-tight` یا `letter-spacing` منفی است، در نسخه فارسی آن را کاملاً حذف کن و روی `tracking-normal` (`0em`) قرار بده (چون حروف فارسی به هم چسبیده‌اند و منفی شدن فواصل کلمات را مخدوش می‌کند).
* **کف ارتفاع خط تیترها (Heading Line-Height Floor):** در تایتل‌های درشت (H1, H2, H3)، استفاده از `leading-none` (1) یا `leading-tight` (1.25) اکیداً ممنوع است؛ زیرا سرکش‌ها، کلاهک‌ها و نقطه‌های بالا و پایین با سطر مجاور برخورد می‌کنند. همیشه از `leading-[1.38] sm:leading-[1.35] lg:leading-[1.32]` استفاده کن.
* **ارتفاع خط متن بدنه (Body Line-Height):** برای متن‌های بدنه، پاراگراف‌ها و توضیحات کارت‌ها همیشه از `leading-[1.75]` تا `leading-[1.85]` استفاده کن تا خوانایی روان باشد.
* **ریتم فاصله‌گذاری بج و تیتر (Eyebrow & Heading Rhythm):** هرگز بج بالای تیتر را به تیتر نچسبانید (`mb-2` یا `mb-3` ممنوع است). همیشه فاصله `mb-5` تا `mb-6` و فاصله تیتر تا توضیحات زیرین حداقل `mt-5` تا `mt-6` باشد.
* **توازن خطوط تیتر:** روی تیترها ویژگی `text-wrap: balance` اعمال شود تا کلمات پایانی به تنهایی در خط بعد نیفتند.
* **محافظت از ویوپورت هیرو و دکمه CTA:** در بخش‌های هیرو تک‌صفحه‌ای (100vh)، برای جلوگیری از رانده شدن دکمه CTA به زیر خط تا در لپ‌تاپ‌های ۱۳۶۶x۷۶۸:
  - سطر اول تیتر حداکثر ۱۰-۱۲ کاراکتر، سطر دوم ۱۰-۱۲، سطر سوم ۸-۱۰ کاراکتر (`whitespace-nowrap`).
  - توضیح کوتاه حداکثر ۷۰-۸۵ کاراکتر با کلاس `line-clamp-2`.
  - حاشیه تنفس پایین دکمه حداقل ۱۲۰ تا ۱۷۰ پیکسل تضمین شود.
* **اعداد فارسی در سطح CSS:** روی کانتینر اصلی، ویژگی `[font-feature-settings:'ss01']` را اعمال کن تا تمام اعداد با گلیف اصیل فارسی رندر شوند.

### ۳. انتخاب فونت Variable فارسی در Next.js
* جایگزین فونت‌های خنثی و تکنولوژیک (Inter, Geist, SF Pro): **Vazirmatn** (متن‌باز) یا **IRANSansX / Dana** (سازمانی).
* جایگزین فونت‌های هندسی و هیروهای لوکس (Plus Jakarta Sans, Clash Display): **Peyda** یا **Yekan Bakh**.

### ۴. قانون طلایی انیمیشن‌های متنی (GSAP SplitText & React Bits در فارسی)
* **ممنوعیت مطلق Character Split:** در زبان فارسی، تکه کردن متن به کاراکترها (`splitType: "chars"` یا `.split('')`) باعث جدا شدن حروف چسبیده (مانند «ه و ش م ن د») و تخریب کامل کلمات می‌شود.
* **راهکار اجباری:** در تمام انیمیشن‌های متنی، متن را **فقط و فقط بر اساس کلمات (`words`) یا خطوط (`lines`)** تکه و انیمیت کن (`text.split(' ')`).

### ۵. معکوس‌سازی بردارهای حرکتی و آیکون‌ها
* **محور X در GSAP و Framer Motion:** هر انیمیشنی که در نسخه انگلیسی از چپ وارد می‌شود (`from({ x: -100 })`)، در نسخه فارسی علامت آن باید قرینه شود (`from({ x: 100 })`).
* **آیکون‌های جهت‌دار:** در دکمه‌های CTA، آیکون `ArrowRight` یا `ChevronRight` با `ArrowLeft` و `ChevronLeft` جایگزین شود (یا کلاس `rtl:-scale-x-100`). ترنزیشن Hover هاور آیکون نیز به `group-hover:-translate-x-1` تغییر یابد.
* **زوایای گرادیان:** گرادینت‌های افقی `bg-gradient-to-r` به `bg-gradient-to-l` تبدیل شوند.

*(راهنمای تفصیلی در [references/rtl-persian-typography-engine.md](references/rtl-persian-typography-engine.md) آمده است).*

## ۷. معماری حرکتی و تعاملی (Lenis + GSAP ScrollTrigger + React Bits)

1. **اسکرول نرم و مومنتوم با Lenis:** هماهنگ‌سازی تیکر Lenis با ScrollTrigger در کامپوننت پرووایدر.
2. **انیمیشن‌های ورود و اسکرول با GSAP (`@gsap/react`):**
   - ترتیب ۵ مرحله‌ای: ۱) ظهور پس‌زمینه و نورها، ۲) ورود نشان بالا (`y: 20 -> 0`)، ۳) ورود تیتر کلمه‌به‌کلمه با `stagger: 0.08`، ۴) ورود زیرعنوان و CTAها، ۵) ورود موکاپ با پارالکس در اسکرول (`scrub: true`).
3. **جلوه‌های بصری مدرن React Bits:** پیاده‌سازی حداقل ۱ یا ۲ الگوی مدرن شامل:
   - **SplitText / BlurText:** ورود کلمات با افکت بلور تدریجی (`filter: blur(10px) -> blur(0px)`).
   - **Magnetic Button:** دکمه اصلی با جاذبه مغناطیسی به سمت موس.
   - **Spotlight Card / Border Beam:** هاله نوری متحرک روی حاشیه یا زمینه کارت‌ها هنگام حرکت موس.
   - **Aurora / Mesh Background:** پس‌زمینه‌های گرادینت متحرک ارگانیک.

*(کدهای کامل در [references/interactive-motion-stack.md](references/interactive-motion-stack.md) موجود است).*

## ۸. جعبه سیاه درس‌های تجربی و ضدخطا (Hardened Quality Gate)

برگرفته از باگ‌های واقعی حل‌شده در پروژه‌های فرانت‌اند (مستند کامل در [references/hardened-replication-lessons.md](references/hardened-replication-lessons.md)):

1. **قوانین استکینگ چسبنده کارت‌ها (Sticky Stacking Cards - روی هم آمدن کارت‌ها):**
   - **ممنوعیت مطلق `overflow-hidden`:** هیچ کانتینر والدی نباید `overflow-hidden` داشته باشد زیرا رفتار sticky را کاملاً متوقف می‌کند.
   - **ترتیب لایه‌ای صعودی (`z-10`, `z-20`, `z-30`):** کارت بعدی همیشه با اسکرول **روی** کارت قبلی قرار می‌گیرد و آن را می‌پوشاند.
   - **سطح ۱۰۰٪ کدر (`bg-surface` یا `bg-[#f5f5f5]`):** جلوگیری از دیده شدن متن کارت زیرین.
   - **سایه ارگانیک و پدینگ انتهایی:** سایه عمیق نرم و پدینگ انتهایی `pb-48` تا `pb-60`.
2. **منوی شناور و زمان‌بندی دقیق اسکرول:** سنجش آستانه دقیق اسکرول با Playwright در سایت مرجع (مثلاً ۱۶۵۰px) تا منو زودتر روی هیرو و محتوای بالایی ظاهر نشود.
3. **ویدیوهای پس‌زمینه و بودجه ارتفاع تک‌اسکرین:**
   - دانلود ویدیوهای لوپ با اتریبیوت‌های `autoPlay loop muted playsInline`.
   - محدود کردن ارتفاع کارت‌ها به `480px-520px` برای سکشن‌های تک‌صفحه‌ای تا کاربر در لپ‌تاپ نیاز به زوم‌اوت نداشته باشد.
4. **کاروسل‌های خودکار افقی:** استفاده از `embla-carousel-autoplay` با تاخیر ۳.۵ ثانیه و توقف روی هاور.
5. **گرافیک‌های چندلایه و موک‌آپ‌های سه‌بعدی:** تفکیک پترن وکتوری پس‌زمینه و موک‌آپ ۳بعدی با پرسپکتیو CSS و سایه عمیق.

## ۹. چک‌لیست نهایی ممیزی و راستی‌آزمایی پیش از تحویل به کاربر

پیش از اعلام اتمام کدنویسی، اجرای این فرآیند **الزامی** است:

### ۱. اجرای اسکریپت ممیزی خودکار:
```bash
node .agents/skills/frontend-replicator/scripts/audit-replica.mjs --url "http://localhost:3000/[ROUTE]"
```
- [ ] هیچ عنصر چسبنده‌ای والدی با `overflow: hidden` ندارد.
- [ ] هیچ ریسورس رسانه‌ای (عکس یا ویدیو) خطای ۴۰۴ ندارد.
- [ ] اسکرول افقی ناخواسته در صفحه وجود ندارد (`scrollWidth <= innerWidth`).

### ۲. چک‌لیست کیفیت بصری و دسترسی‌پذیری (UI/UX Pro Max):
- [ ] هیچ ایموجی به عنوان آیکون رابط کاربری استفاده نشده است (صرفاً Lucide / SVG).
- [ ] کنتراست متن اصلی حداقل ۴.۵:۱ در هر دو تم روشن و تاریک رعایت شده است.
- [ ] اندازه تاچ تارگت تمام المان‌های کلیک‌پذیر در موبایل حداقل ۴۴×۴۴ پیکسل است.
- [ ] حلقه‌های فوکوس کیبورد (`focus-visible:ring-2`) روی تمام دکمه‌ها و لینک‌ها فعال هستند.
- [ ] تنظیمات `prefers-reduced-motion` برای کاربران حساس به انیمیشن رعایت شده است.

### ۳. چک‌لیست فارسی‌سازی، ریتم فضایی و RTL:
- [ ] در ویوپورت‌های هیرو تک‌صفحه‌ای (100vh)، دکمه CTA هرگز به زیر خط تا در لپ‌تاپ ۱۳۶۶x۷۶۸ نرفته است.
- [ ] در انیمیشن‌های متنی، حروف پیوسته فارسی به کاراکترها شکسته نشده‌اند (صرفاً Word/Line Split).
- [ ] تمام فاصله‌ها، موقعیت‌ها و حاشیه‌ها با Logical Properties پیاده‌سازی شده‌اند (`ms`, `me`, `ps`, `pe`, `start`, `end`).
- [ ] ارتفاع خط تیترها (Leading) متناسب با حروف فارسی افزایش یافته (`leading-[1.32]` تا `leading-[1.38]`) و سرکش‌ها تصادم ندارند.
- [ ] بج بالای تیتر (Eyebrow) فاصله سخاوتمندانه `mb-5` تا `mb-6` با تیتر دارد.
- [ ] پاراگراف‌های بدنه دارای ارتفاع خط تنفس‌دار `leading-[1.75]` تا `leading-[1.85]` هستند.
- [ ] بردارهای افقی انیمیشن و آیکون‌های جهت‌دار برای RTL معکوس شده‌اند.
- [ ] اعداد فارسی با `[font-feature-settings:'ss01']` فعال شده‌اند.

### ۴. بررسی صحت بیلد بدون خطا:
```bash
npm run build
```
- بیلد Next.js باید با کد خروج ۰ و بدون خطای تایپ‌اسکریپت پایان یابد.
